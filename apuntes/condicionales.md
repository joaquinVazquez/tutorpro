## if, elif y else
Un condicional ejecuta código solo si se cumple una condición. Ejemplo: if edad >= 18: print("Mayor de edad") else: print("Menor de edad"). Con elif se agregan condiciones intermedias. Después de if, elif y else va dos puntos, y el código de adentro va con sangría.

## Operadores de comparación
Se usan para formar condiciones: == (igual), != (distinto), > (mayor), < (menor), >= (mayor o igual), <= (menor o igual). Error común: usar = (asignar) en lugar de == (comparar).

## Operadores lógicos
and exige que se cumplan las dos condiciones, or que se cumpla al menos una, y not invierte el resultado. Ejemplo: if edad >= 18 and tiene_credencial: print("Puede pasar").
