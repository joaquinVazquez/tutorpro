## Qué es una variable
Una variable es un nombre que guarda un valor en la memoria. En Python se crea con el signo igual: edad = 15. No hace falta declarar el tipo; Python lo deduce solo.

## Tipos de datos básicos
Los tipos más comunes son int (números enteros, como 7), float (decimales, como 3.5), str (texto, como "hola") y bool (verdadero o falso: True o False). Con la función type() puedes ver el tipo de una variable.

## Reglas para nombrar variables
El nombre puede tener letras, números y guion bajo, pero no puede empezar con número ni tener espacios. Python distingue mayúsculas de minúsculas: nombre y Nombre son variables distintas. Se recomienda usar minúsculas y guion bajo, como total_compra.

## Cambiar el valor de una variable
Una variable puede recibir un nuevo valor en cualquier momento: contador = 1 y luego contador = contador + 1 deja contador en 2. También se puede escribir contador += 1.
