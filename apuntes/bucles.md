## Bucle for
El for repite código para cada elemento de una secuencia. Ejemplo: for numero in range(1, 4): print(numero) imprime 1, 2 y 3. range(1, 4) empieza en 1 y termina antes del 4. También sirve para recorrer listas: for fruta in frutas: print(fruta).

## Bucle while
El while repite código mientras una condición sea verdadera. Ejemplo: contador = 0 y luego while contador < 3: print(contador); contador += 1. Si la condición nunca se vuelve falsa, el bucle es infinito, así que hay que cambiar la variable dentro del bucle.

## break y continue
break detiene el bucle por completo. continue salta a la siguiente repetición sin terminar la actual.
